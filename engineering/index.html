System Simulator.

IoT Sensor-to-Cloud
Pipeline Simulator.

Educational Python simulator of an end-to-end IoT data pipeline, inspired by the architecture of my CISNR E. coli rapid-detection kit work: synthetic sensor nodes (temperature/pH/turbidity) stream readings over a configurable lossy wireless link with ARQ retries, a gateway validates CRCs and deduplicates, and a mock cloud API ingests the data — with delivery-rate, latency, and data-integrity analysis. All data is synthetic; clearly labeled as a demonstration, not the actual CISNR system.

View the code on GitHub ↗

E. coli Detection Kit —
Computer Vision Demo.

Educational computer-vision demo of the detection side of my CISNR E. coli rapid-detection kit work: procedurally generated synthetic plate images, an OpenCV pipeline (top-hat filtering, adaptive thresholding, watershed segmentation), and colony-count accuracy analysis against known synthetic ground truth. Mean count error 2.6 colonies on test plates. Strictly a demonstration — not a medical device, not the actual CISNR system.
